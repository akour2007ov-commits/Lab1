## В работе был использован ии.
## Промт: 
**Какие команды есть в NumPy. Название и что делает**
## Ответ:
**В библиотеке NumPy содержатся тысячи функций. Ниже собраны самые важные и часто используемые команды, сгруппированные по логическим категориям, чтобы в них было удобно ориентироваться.**
## 1. Создание массивов и матриц
`np.array()` — Создаёт одномерный или многомерный массив из списков/кортежей.

`np.zeros(shape)` — Создаёт массив указанного размера, полностью заполненный **нулями**.

`np.ones(shape)` — Создаёт массив указанного размера, полностью заполненный **единицами**.

`np.full(shape, value)` — Создаёт массив, заполненный **заданным числом** (`value`).

`np.eye(n)` — Создаёт квадратную **единичную матрицу** размера n × n.

`np.arange(start, stop, step)` — Создаёт последовательность чисел с заданным шагом (аналог `range`).

`np.linspace(start, stop, num)` — Создаёт массив из `num` чисел, **равномерно распределённых** в отрезке.

## 2. Изменение формы и структуры массивов
`.shape` — свойство, которое показывает размеры массива (например, количество строк и столбцов).

`.reshape(new_shape)` — изменяет форму массива без изменения его данных (например, превращает вектор из 12 элементов в матрицу 3 × 4).

`.T` — свойство, выполняющее транспонирование (поворот) матрицы (строки становятся столбцами).

`.flatten()` или `.ravel()` — «разглаживает» многомерную матрицу, превращая её в простой одномерный вектор.

`np.ogrid` / `np.mgrid` — генерирует координатные сетки (часто используется для математических масок и рисования фигур).

## 3. Математические и статистические вычисления
Почти у всех этих функций есть параметр axis (например, axis=0 для расчёта по столбцам, axis=1 — по строкам).

`np.sum()` — вычисляет сумму элементов массива.

`np.mean()` — находит среднее арифметическое (математическое ожидание).

`np.var()` — вычисляет дисперсию элементов.

`np.std()` — находит среднеквадратическое (стандартное) отклонение.

`np.min()` / `np.max()` — находят минимальное и максимальное значение в массиве.

`np.argmin()` / `np.argmax()` — возвращают индексы минимального и максимального элементов.

`np.unique()` — находит все уникальные (неповторяющиеся) элементы и возвращает их в отсортированном виде.

## 4. Линейная алгебра и операции над матрицами
`@` (оператор) или `np.dot(A, B)` — выполняет классическое матричное умножение.

`np.convolve(a, v, mode)` — вычисляет свёртку двух одномерных последовательностей (активно применяется для расчёта скользящего среднего).

`np.linalg.inv()` — находит обратную матрицу.

`np.linalg.det()` — вычисляет определитель (детерминант) матрицы.

## 5. Фильтрация, условия и логика
`np.where(condition, x, y)` — векторизованный if-else. Возвращает x, если условие верно, и y, если неверно.

`.astype(type)` — приводит массив к новому типу данных (например, превращает float или bool в целые числа int).

`np.any()` — возвращает True, если хотя бы один элемент массива истинный.

`np.all()` — возвращает True, только если абсолютно все элементы массива истинные.

## 6. Генерация случайных чисел (np.random)
`np.random.default_rng(seed)` — создаёт современный генератор случайных чисел.

`rng.normal(loc, scale, size)` — генерирует массив случайных чисел по нормальному (гауссовскому) закону распределения.

`rng.random(size)` — генерирует случайные числа с плавающей точкой в диапазоне [0.0, 1.0).

`rng.integers(low, high, size)` — генерирует случайные целые числа в заданном диапазоне.
